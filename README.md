# MUMU CIRCUIT · Unity 웹 시험판

Unity 6으로 만든 해안 드라이빙 게임의 브라우저용 실행본입니다.

**[웹에서 플레이하기](https://reinhardt7177-lab.github.io/mumu-circuit-unity-web/)**

2026-10-01 업데이트: 고해상도 수프라 차체·헤드램프·매끈한 유리 마감, 차량별 도장/차고 회전·확대, 라이벌 1vs1·90초 드리프트·미니맵·기록 기능을 반영했습니다. 새 게임 파일은 `Build/v47/`에 두어 이전 브라우저 캐시와 구분합니다. 앞으로 웹 버전을 기준으로 업데이트합니다.

차고에서 GR Supra, SLK Roadster, Mustang GT 중 한 대를 골라 항구·해변·도심·산길·등대·해상대교로 이어지는 코스를 달릴 수 있습니다.

| 조작 | 키 |
|---|---|
| 가속 / 제동 | W / S 또는 ↑ / ↓ |
| 조향 | A / D 또는 ← / → |
| 핸드브레이크 | 왼쪽 Shift |
| 후진 / 도로 복귀 | Q / C |
| 일시정지 / 음소거 | Esc / M |

첫 접속에는 약 89MB의 게임 파일을 내려받습니다. 브라우저에서 차고 도장/확대, 라이벌 시작·실제 가속·미니맵·일시정지를 확인했습니다. 모바일 성능과 전체 코스 완주는 아직 별도로 검증하지 않았습니다.

이 저장소에는 배포용 WebGL 파일만 있습니다. Unity·Blender 제작 원본은 포함하지 않습니다. 한글 표시용 Noto Sans KR의 라이선스는 [여기](licenses/NotoSansKR-OFL.txt)에 있습니다.
