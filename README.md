# MUMU CIRCUIT · Unity 웹 시험판

Unity 6으로 만든 해안 드라이빙 게임의 브라우저용 실행본입니다.

**[웹에서 플레이하기](https://reinhardt7177-lab.github.io/mumu-circuit-unity-web/)**

2026-10-01 UI 업데이트: MIDNIGHT / SIGNAL 스타일로 차고·주행·일시정지·결과 화면을 개편했습니다. 왼쪽 차고 메뉴, 오른쪽 차량 감상, 지도/속도계 분리, 주행 HUD를 숨기는 일시정지 메뉴, 큰 결과 시간·점수, 전용 로딩·전체 화면 셸을 사용합니다. 실제 실내 차고 메시·전시 조명/반사, 고정 굵기 한글과 좁은 숫자 글꼴, 차량 썸네일·벡터 아이콘·원형 도장칩을 추가했습니다. 도로 표면과 낮 조명, 웹 렌더 품질도 보정했습니다. 새 게임 파일은 `Build/v52/`에 두어 이전 브라우저 캐시와 구분합니다. 앞으로 웹 버전을 기준으로 업데이트합니다.

v52 주행 안내: 실제 주도로 방향에서 최대 140m 앞의 코너 방향·거리·급커브 안내를 표시합니다. 역주행·주도로 이탈·메뉴·결승 이후에는 안내를 숨깁니다. 정적인 HUD 배치와 글꼴의 중복 갱신도 줄였습니다. 이는 경로 탐색이나 자동 제동 기능은 아닙니다.

고해상도 수프라 차체·헤드램프·유리 마감, 차량별 도장/회전·확대, 라이벌 1vs1·90초 드리프트·기록 기능도 유지했습니다.

차고에서 GR Supra, SLK Roadster, Mustang GT 중 한 대를 골라 항구·해변·도심·산길·등대·해상대교로 이어지는 코스를 달릴 수 있습니다.

| 조작 | 키 |
|---|---|
| 가속 / 제동 | W / S 또는 ↑ / ↓ |
| 조향 | A / D 또는 ← / → |
| 핸드브레이크 | 왼쪽 Shift |
| 후진 / 도로 복귀 | Q / C |
| 일시정지 / 음소거 | Esc / M |

첫 접속에는 약 93MB의 게임 파일을 내려받습니다. PC 브라우저와 960×600 화면에서 차종/도장 선택, 라이벌 시작·지도·메뉴, 결과와 차고 복귀, 키보드 일시정지/재개를 확인했습니다. 모바일 실기기 성능과 전체 코스 완주는 아직 별도로 검증하지 않았습니다.

이 저장소에는 배포용 WebGL 파일만 있습니다. Unity·Blender 제작 원본은 포함하지 않습니다. 한글 표시용 Noto Sans KR의 라이선스는 [여기](licenses/NotoSansKR-OFL.txt)에 있습니다. 영문/숫자용 Barlow Condensed의 [OFL 라이선스](licenses/BarlowCondensed-OFL.txt)도 동봉합니다.
